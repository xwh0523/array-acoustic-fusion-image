# Array Acoustic Fusion Image Framework

This repository provides the source code and example data associated with the manuscript:

**An Imaging Framework for Array Acoustic Logging: Integrating Slowness and Energy Attributes for Fracture Detection**

The repository contains two software modules:

1. Lithology-constrained slowness-envelope reconstruction
2. Multi-attribute fusion-image generation and composite indicator extraction

The original field logging data used in the manuscript are not publicly available due to confidentiality restrictions. Synthetic or desensitized example datasets are provided for testing and demonstration.
